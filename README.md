## Projects

### 1. Spam Detector 

The first project in this repository is a Spam Detection Model.

#### Objectives
- Clean and preprocess text data
- Apply Natural Language Processing (NLP)
- Extract text features using TF-IDF
- Train Machine Learning models
- Evaluate model performance
- Predict whether a message is Spam or Not Spam

#### Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
